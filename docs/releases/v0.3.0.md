# Garlic v0.3.0 — development prerelease

Adds an authenticated HTTPS/HTTP2 proxy transport alongside the existing Infinity HTTP task exchange.

- Entry/exit roles and local HTTP CONNECT adapter; bounded concurrent streams.
- Full-duplex TCP 443 relay over HTTP/2; private/local destinations blocked.
- Multiple configured exit nodes; new tunnels distributed round-robin, without replaying active streams.
- DNS wire messages inside the authenticated channel; local UDP stub; Cloudflare DoH with Google fallback at the exit.
- Bootstrap IP override preserves domain, TLS SNI and certificate verification.
- Caddy configuration for Let's Encrypt; HTTP/3 disabled and HTTP/1 application requests rejected.
- Safer task mutation retries, bounded upstream response reads, and checked completion replays.

## Validation

Development environment: Rust 1.99.1, Linux x64 release build, six unit tests, original Infinity integration tests, and local TLS/HTTP2 proxy integration tests. Proxy relay and DNS tests use mock exit/resolver services; they do not establish real public egress. Windows x64 cross-compilation succeeded; Windows runtime was not checked there. Release CI performs native Linux and Windows workspace builds and unit tests, and Linux integration checks.

## Limitations

Not production ready or full Garlic v1.0. No Android APK or OS-level VPN adapter, no exact Chromium outer TLS/HTTP2 fingerprint, no message-level digital signatures, no production user/role management or per-user quotas. TLS and bearer authentication are implemented. Existing task persistence remains JSON snapshots rather than a transactional SQL queue. Real domains, certificate issuance, foreign exit operation and device DNS leakage require deployment validation.
