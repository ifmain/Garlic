# Модуль протокола Garlic Alpha, ABI 2

Модуль описывает две операции над пакетом обмена. Клиент сначала кодирует тело (`base` или `selective-ack`), затем упаковывает его (`fragments` или `tlv`). На приёме операции выполняются в обратном порядке. Номер версии от 128 до 255 передаётся при открытии обеих WebSocket-линий. Каждая линия должна подтвердить выбранную версию.

```json
{"version":128,"body":"selective-ack","frame":"tlv"}
```

Это полный язык модуля. Две операции реализованы в поставляемом клиенте. В формате отсутствуют адреса памяти, вызовы ОС, циклы, пользовательские функции и импорты. Указатели, ключи, сокеты и содержимое файлов в модуль не передаются. Даже правильно подписанное описание с неизвестной инструкцией или дополнительным полем отклоняется. Граница изоляции находится в валидаторе и встроенных кодеках Rust. Ошибки самого клиента остаются частью модели угроз.

## Публикация

1. Включите такое же описание в `modules` серверного манифеста. Для несовместимой замены используйте новый номер версии и временно оставьте оба номера включёнными.
2. Подпишите приведённый JSON на машине издателя. Пример команды приведён ниже. Укажите UUID владельца сети, номер публикации больше предыдущего и срок действия в секундах Unix. Клиент должен заранее доверять публичному ключу издателя.
3. Опубликуйте полученный конверт как файл `GARLIC_RECORD_PROFILE_FILE` с атомарной заменой. Сервер перечитывает файл при запросе информации. Клиент проверяет предложение при открытии нового потока. Действующие потоки сохраняют ранее выбранное описание.

```text
python sign_profile.py --key publisher.pem --network UUID --sequence 2 --expires UNIX_TIME --frame-bytes 4096 --module module.json record-profile.json
```

Для возврата к предыдущей схеме опубликуйте её с большим номером публикации. Для возврата к встроенным протоколам подпишите профиль без аргумента `--module`. Если сервер перестаёт объявлять номер версии или истёк срок подписанного профиля, новые соединения снова согласуют встроенный протокол. Новые примитивы кодирования требуют выпуска доверенной сборки приложения.
